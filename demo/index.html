Built on the spectrl JavaScript implementation — the same spectrl2 format as the Python package on PyPI. Tokens use PSI-MS CV accessions, MS-Numpress + zlib (as in mzML), and ProForma 2.0. Open this page's URL on another device and the spectrum travels with it. See the specification.
